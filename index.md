# J.A.R.V.I.S. Personal Assistant

### A private, locally operated AI desktop assistant

J.A.R.V.I.S. is a personal AI assistant designed to run on a Windows computer, helping with productivity, desktop automation, organization, and daily briefings.

## Google Gmail and Calendar Integration

With the user's explicit permission, J.A.R.V.I.S. can connect to Google services to provide a personalized daily briefing.

- **Gmail:** Reads message metadata, including sender, subject, date, and labels, to identify unread messages. It does not request email message bodies.
- **Google Calendar:** Reads calendar events to report upcoming appointments.

The integration requests read-only permissions. It is not designed to send, delete, or modify emails or calendar events.

## Privacy and Security

J.A.R.V.I.S. processes Google account information locally on the user's computer. Google authorization credentials are stored locally using Windows encryption.

This public website is informational only. It does not receive or store Gmail messages, calendar events, or Google authorization credentials.

Read the [J.A.R.V.I.S. Privacy Policy](https://recoil-png.github.io/privacy.html).

## Availability

J.A.R.V.I.S. is currently a personal-use desktop project and is not offered as a public service.
